# 博客编辑器

在博客仓库根目录运行以下命令。第一次使用时先运行一次 npm ci。

```sh
npm run editor
```

打开 [本地编辑器](http://127.0.0.1:5174/__editor/)。在标题下方直接编辑整篇正文，按回车换行。工具栏可插入图片、链接和附件，也可以选择封面。「Markdown 源码」切换到整篇源码，「博客预览」按博客主题查看文章。

正文中可以选图或粘贴图片。点中图片后，可在下方写图注，拖侧边改宽度、拖底边改高度、拖角按比例缩放。「自由」对齐时可在正文栏内左右拖动图片，开启自动居中可回到栏中央。

「保存草稿」保存到 drafts/editor/，下次启动后从「打开」继续。「保存到博客」写入 docs/tech/ 或 docs/essay/，图片和附件同时进入 docs/public/。用 Git 提交并推送到 main 后发布。

预览使用同一套 VitePress 配置和主题。终端按 Ctrl+C 停止编辑器。
