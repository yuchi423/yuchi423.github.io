# 一个阶段的落幕与反思

曾经偶然了解到，当外部环境变得混乱时，人们会倾向于把认知局限在一个具体的领域。今年五月，大一下的时候，我正式开始了我就业向学习的准备，零零散散、牵牵扯扯，日复一日数小时的学习安排也算是有了积累。前段日子四处海投了一阵子，慢慢意识到寂静有的时候比否定要更令人脱力。可能是哪里准备得不够好，可能只是因为他不要我。这个阶段我想也差不多要结束了。19岁的生命浪费在等待回复和背诵经书上，奢侈无比又有些荒诞的有趣

先说结论，在大一下把绝大多数精力投资于就业技术栈学习，是个不明智的决策。半年来，我在后端学习上的纯专注时间大概在600+h，若是按照csdiy的判断，即使是csapp这样的大部头课程，也大致只需要150h的纯专注时间。我想后者的收益显然大于前者。大一的时间本不应把自己反复背熟

同样，最近才开始意识到提前准备并不意味着万事顺利。金九银十不一定意味着机会丰富，因为你很可能会被最简单的年级限制卡在门外。何况面试不是标准化考试，个人能力和面试表现可能是取得结果的重要条件，但也只是众多因素里面，我们堪堪能掌握的两个。其他有的因素我们只能适应，有的因素我们根本无法控制。如果等到明年再投递，又要耗费相当长的时间重新背八股、刷算法，时间就被空转浪费……何况从招聘者视角出发，我也一定会对一个大二上学生有所顾虑。如果日常实习生大概率是只为了一个开袋即食的便宜耗材，太早的年纪相反可能正是限制

因此，过早准备更有可能面对的是「学习周期和招聘周期」间的错位，即使我已经做到尽力而为。可是独轮车蹬得再快也不能比日历更早到达明天

现在才慢慢想明白这些，至于当初为什么会迫切地决定All in本科就业，还要回到半年前的情景。当时有两个人让我大受震撼：一个是mirofish的作者，北邮本科毕业拿下3000w投资的Baifu；还有一个是酥神lofisu。老实说，我仍然处于一个会被神话故事打动的年纪。我开始相信这世界上大部分限制本质是自我设限、我完全可以用一个足够激进的方式为自己创造不一样的人生。年初的互联网，入目满是超级个体、工业革命、OPC的宏大叙事……沉醉而疯狂，残酷天使的行动纲领降临，勇敢的少年快去创造奇迹

总是庆幸年龄尚早，干什么都不算晚。接下来的时间再没必要慷慨愤昂。去顺手学点感兴趣的东西、做些感兴趣的事，等到合适的时候再去投递。

不再选定新的圣杯，我也想慢慢学着从无聊的生活里感受乐趣

明年春夏的事就留到明年春夏再说，你瞧，前天才刚立冬呢。
