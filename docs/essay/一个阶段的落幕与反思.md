# 一个阶段的落幕与反思

曾经听访谈时偶然了解到，当外部环境变得混乱时，人们会倾向于把认知局限在一个具体的领域。今年五月，大一下的时候，我正式开始了我就业向学习的准备，准确点说，是后端的准备。零零散散、牵牵扯扯半年来，每天数小时的专注时长和计划安排也算是有了点积累。前些日子又四处海投了一阵子，慢慢意识到寂静有的时候比否定要更令人脱力。这个阶段我想也差不多要结束了。19岁的生命浪费在等待回复和背诵经书上，奢侈无比又有些荒诞的有趣

先说结论，在大一下的时间点，把绝大多数精力投资于面试向的就业技术栈学习，是个愚蠢的决策。我半年来在后端学习上的纯专注时间大概在600+h，而如果按照csdiy的判断，即使学习完csapp这样的大部头课程也大致只需要150h的纯专注时间，我相信在大一的阶段，后者的重要性和ROI都要远高于前者。毕竟，达到一个足以应付后端面试的程度远远不需要投入那么多的认知资源，真的。

而且，毋论技术栈准备的水平深浅，在大二上的阶段你都几乎不可避免地面对「学习准备周期和招聘周期错位」的矛盾。金九银十本身并不一定意味着机会丰富，因为它大概率只是给老资历们更多争抢的名额、不意味着你能喝上一口汤。何况从招聘者视角出发，面对一个大二上学生我也一定会有所顾虑。毕竟公司招日常实习生，我想大概率只是为了一个开袋即食的便宜耗材。既然人那么多，我没有理由承担你年龄资历带来的客观风险

（虽然站在招聘者的视角考虑如何拒绝自己这点听上去就足够难绷，但为了做出解释我不得不这么做

多年来做题家的生活惯性让我相信：越早开始对应着越强的优势。但实习并不是这样，如果你开始的足够早，你或许会被最简单的年纪限制挡在门外。面试不是标准化考试，个人能力、面试表现是取得实习结果的必要条件，但这只是我们能控制的因素，也只是众多因素的其中两个。而有的因素我们只能适应，有的因素我们则根本无法控制。个人准备程度和招聘结果间或许并不存在一种线性关系，我已经做到尽力而为。之后呢？之后我也不知道。干脆就让命运自由地穿过身体吧

当然，这些都是今天我才想明白的东西，至于当初为什么会如此迫切地决定All in本科就业，还要回到半年前的情景。当时直接让我震撼的人有两个：一个是mirofish的作者，北邮本科毕业拿下3000w投资的Baifu；还有一个是酥神lofisu。老实说，我仍然处于一个会被神话故事打动的年纪。我开始相信这世界上大部分限制本质是自我设限，我完全可以用一个够激进的方式为自己选择不一样的生活。赶上年初风口正盛，入目满是超级个体、工业革命、OPC的宏大叙事……沉醉而疯狂，残酷天使的行动纲领降临，勇敢的少年快去创造奇迹

半年的时间拉到人生的尺度或许也只是微小的断面，何况它也远远称不上是被浪费。我现在的年纪，干什么都不算晚。接下来的日子，先好好学会生活、小火慢炖维持学过的内容，再去顺手学点感兴趣的东西、做些感兴趣的事，等到合适的时候再去投递。

不再选定新的圣杯，我也想慢慢学着从无聊的生活里感受乐趣

明年春夏的事就留到明年春夏再说，你瞧，前天才刚立冬呢。
